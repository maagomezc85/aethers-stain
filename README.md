# AETHER'S STAIN — El Ciclo Manchado

Videojuego 2.5D en primera persona (motor Raycaster) perteneciente al proyecto de narrativa transmedia **Crónicas del Humedal / Hemera**.

Encarnas a **EFE ("El Manchado")** en las entrañas de un humedal industrial en ruinas. Usa tu látigo mecano-espinoso, evade a las Ninfas de Libélula y recolecta los biochips plateados a lo largo de **4 sectores + Epílogo del Gran Sol**.

## Jugar en línea

- **URL jugable (GitHub Pages):** https://maagomezc85.github.io/aethers-stain/

## Controles

- **W / A / S / D** (o flechas): Moverse
- **Ratón** (haz clic en la pantalla del juego para activar *Pointer Lock*): Girar cámara horizontal y verticalmente
- **Q / E** o **← / →**: Girar cámara con teclado
- **Espacio** o **Clic izquierdo**: Atacar con el Látigo Mecano-Espinoso
- **ESC**: Liberar el ratón
